Blacknet · Verifiable Computation

The zkVM

Compute once, verify everywhere. Run a program off-chain, then hand anyone a tiny proof they ran it right.

Re-executing other people's computation is how chains stay honest — and why they're slow. The zkVM replaces re-execution with a single succinct proof: the work happens once, and the proof that checks it stays the same size no matter how big the work was.

Each step is folded into a running accumulator instead of being proven on its own. At the end, one succinct opening — about 37 KB — attests to the entire run.

01

Execute

Run the program on the virtual machine and record its trace — every register and memory step it took.

02

Arithmetize

Turn the trace into R1CS constraints: a system of equations that holds if and only if the program executed honestly.

03

Commit

Bind the witness with an Ajtai / SIS lattice commitment — short, hiding, and post-quantum hard to forge.

04

Fold

HyperNova folds each step into a single accumulator (IVC). The work compounds; the thing you carry forward does not grow.

05

Open

Produce one succinct proof — about 37 KB, constant in the number of steps — that opens the accumulator.

06

Verify on-chain

Kernel transactions (VerifiedComputation, DeployProgram, ComputeReference) check the proof. Anyone verifies; no one re-runs.
